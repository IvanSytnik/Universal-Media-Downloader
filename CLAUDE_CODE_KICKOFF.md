# Как запустить Day 11B в Claude Code

Положи `TASK_Day11B.md` в корень проекта рядом с `PROJECT_SPEC.md` / `HANDOFF.md` /
`STRUCTURE.md`. Затем в Claude Code открой проект и дай стартовый промпт:

---

**Стартовый промпт (скопировать целиком):**

> Ты — Senior Software Architect + Senior Python Engineer на проекте Universal
> Media Downloader. Отвечай на русском.
>
> Прочитай перед работой: `PROJECT_SPEC.md` (источник истины), `HANDOFF.md`,
> `STRUCTURE.md`, `TASK_Day11B.md`. Также глянь `CHANGES.md` (последний патч).
>
> Реализуй задачу из `TASK_Day11B.md` (Day 11B — прогресс скачивания в реальном
> времени). Архитектура в задаче согласована — следуй ей, не переизобретай.
> Соблюдай 5-шаговую дисциплину PROJECT_SPEC §8 и все «пойманные баги» из HANDOFF
> (не наступать снова). Особое внимание: Dependency Rule (downloader/domain не
> знают о Telegram), i18n вне контекста апдейта — только с явной локалью (баг #10),
> захват аргументов в тестах вместо голого мока (урок 11A.1).
>
> План работы:
> 1. Сначала покажи мне план файлов (новые + изменённые) и точки риска — жди «делаем».
> 2. После одобрения реализуй, пиши тесты, прогоняй квалити-гейт
>    (`python -m pytest`, `python -m ruff check .`, `python -m mypy --strict src`).
> 3. Патч трогает worker + bot startup → обязателен live-прогон в docker (урок 9.1),
>    инструкция шагов — в TASK_Day11B.md.
> 4. На выходе обнови `CHANGES.md`, `HANDOFF.md`, `STRUCTURE.md` и подготовь git-коммит.
>
> Начни с плана файлов.

---

## Замечания по среде

- Локальная среда — **Python 3.13** (venv). Квалити-гейт гонять там.
- Live-прогон — через `docker compose up` (bot, worker, redis, postgres,
  telegram-bot-api). Нужен рабочий `.env` (BOT_TOKEN, TELEGRAM_API_ID/HASH,
  USE_LOCAL_BOT_API, порты 5433/6380).
- Claude Code работает прямо в файловой системе проекта — zip-патчи больше не
  нужны, правки применяются напрямую. Формат «инкрементальный zip» из прошлых
  сессий заменяется на прямые правки + git-diff для ревью.

## Что проверить перед коммитом

- Все тесты зелёные, ruff + mypy strict чистые.
- Live-прогон подтвердил: превью редактируется прогрессом, троттлинг работает,
  финал → файл в то же сообщение, mp3-путь ок.
- `.env` не попадает в коммит (в .gitignore с Day 1).
